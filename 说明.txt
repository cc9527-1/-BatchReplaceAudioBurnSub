AI视频合并工具 v4.1 (多路并行 + 字幕烧录 + 人声增强 + 码率控制)

功能：批量去原声 + 替换翻译语音 + 烧录/嵌入字幕 + 缩放 + 人声EQ增强

用法：双击 AI视频合并工具.exe -> 选目录 -> 扫描 -> START

参数：
  分辨率：720p / 1080p / 2K / 4K
  码率：4M / 6M / 8M / 10M / 12M / 15M / 20M
  RC模式（码率控制）：
    VBR (smart)  - 智能可变码率，目标码率为平均，允许峰值，体积/质量最佳平衡（推荐）
    CBR (fixed)  - 固定码率，体积最大，质量最稳定
    CQ (constant quality) - 恒定质量，体积最小，PPT/录屏类视频首选（比CBR小70%）
  并行：2 ~ 6 路（默认4路，CPU占用约50%）
  编码器：AMD GPU (hevc_amf) / CPU (libx264)
  人声增强：原始 / 方案1清晰 / 方案2温暖 / 方案3去齿音 / 方案4会议室
  字幕烧录：硬字幕（纯黑底白字，紧贴底部，字号自动适配）
  字幕嵌入：软字幕（可切换显示）

格式：
  视频文件.mp4 + 视频文件_translated.mp3 + 视频文件_translated.srt
  也支持编号前缀：001 视频.mp4 + 001 视频_translated.mp3
  输出：源目录/_video_out/

v4.1 更新：
  - 新增 RC 模式选择（VBR/CBR/CQ）
  - CQ 模式下视频体积减少约70%，适合PPT/录屏类视频
  - VBR 默认码率降为8M，体积减少约9%
  - 默认并行改为4路
  - GPU硬解（d3d11va）降低CPU占用
  - 每路FFmpeg限制2线程，4路总CPU约50%

  - 修复stderr缓冲区阻塞导致进度卡死
  - 实时进度显示（0%-100%）
